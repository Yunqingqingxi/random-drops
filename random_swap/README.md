# yg-swap — 受伤随机互换位置

> 「打僵尸正欢，突然和 40 格外的苦力怕对视」—— 本包的全部内容，纯混沌喜剧。
> 完全独立的玩法包：自带基础库副本与 `config/yg-swap.json`，可单独安装、任意组合。

| 项目 | 值 |
| --- | --- |
| **mod id** | `yg_swap` |
| **jar** | `yg-swap-<版本>.jar` |
| **配置文件** | `config/yg-swap.json` |
| **环境** | 只在服务端判定，无客户端代码、无自定义网络包 —— 原版客户端直连 |

---

## 一、玩法

任何**生物 / 玩家**受到伤害后，按配置概率（默认 **15%**）与「附近随机一个活体」瞬间互换位置：

- 换位对象在**搜索半径内现场收集**（默认 48 格），不预建名单 —— 任何第三方 mod 的生物
  只要是活体（`LivingEntity`）都可能被选中；想挡掉的用黑名单按 id / 命名空间排除；
- 换位发生时播**末影人音效**，双方玩家收到聊天提示；
- 挂在 Fabric `AFTER_DAMAGE` 上：不参与伤害判定本身（护甲 / 药水 / 附魔保护照常生效），
  **致死伤不换**（死亡流程归掉落 / 战绩系统管）。

**内置的「不劝退」保护**：

| 保护 | 原因 |
| --- | --- |
| 排除盔甲架 / 旁观者 / 已死实体 | 换过去没意义 |
| 排除骑乘中（乘客与坐骑）的实体 | 骑乘换位会把人和马拆到两处 |
| 排除黑名单（默认末影龙 / 凋灵） | Boss 换位等于送人头 |
| 落点是岩浆 / 火则跳过 | 换进岩浆即死，太劝退 |
| 换位后清空双方摔落距离 | 对方攒的摔落不该由我买单 |

## 二、配置（`config/yg-swap.json`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `hurtSwapEnabled` | `true` | 总开关 |
| `hurtSwapChance` | `0.15` | 每次受伤触发概率（0~1；一场战斗大概换一两次，够刺激不打架全靠信仰） |
| `hurtSwapMaxRadius` | `48.0` | 换位对象搜索半径（8~256） |
| `hurtSwapIncludePlayers` | `true` | 换位对象是否含其他玩家（不想要随机 PvP 可关） |
| `hurtSwapClearFallDistance` | `true` | 换位后清空双方摔落距离 |
| `hurtSwapAnnounce` | `true` | 末影人音效 + 双方玩家聊天提示 |
| `entityBlacklist` | 末影龙、凋灵 | 不会被选为换位对象；支持精确 id 与 `命名空间:*`（第三方 mod Boss 在这里挡） |
| `debugLog` | `false` | 调试日志（每次换位打印双方与坐标） |
| `selfTestRolls` | `0` | 开服自检掷骰次数，>0 时开服自动跑一遍（跑完改回 0） |

---

## 三、自检（真服务器，编号包内局部）

`run/config/yg-swap.json` 的 `selfTestRolls` 设成 `200` → `./gradlew runServer --offline`
→ 看 `===== 自检结束：3 项全部通过 =====` → **改回 0**。

| 编号 | 名称 | 覆盖 |
| --- | --- | --- |
| ① | 换位·配置钳制 | 加载后的概率 / 半径在合法区间（开关只回显不断言） |
| ② | 换位·互换+清摔落 | 两实体位置真实对调；双方摔落距离清零 |
| ③ | 换位·对象筛选 | 盔甲架不被选中；黑名单 id 命中；距离上限把远处的猪挡在门外 |

---

## 四、已知限制

- 换位保持各自朝向（只换位置）；
- 跨维度不换 —— 换位对象只在受伤者所在维度找；
- 概率是「每次受伤」独立掷骰：接触伤害 / 弹射物 / 摔落各算一次，高攻速武器会显著放大换位频率（调低 `hurtSwapChance` 即可）。
